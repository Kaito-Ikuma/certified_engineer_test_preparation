# DB初版の設計と確認状態

## 正本と再現性
`data/questions.csv`を正本とする。`data/classifications.csv`はその分類部分と根拠を出力したビューで、独立編集しない。
初期DBは`make initial`で保存済み認識結果から再構築できる。手作業による境界・分類補正は`config/*_overrides.json`へ保存する。
査読1ファイルが存在する場合、初期一括再構築を停止し、凍結後データを不用意に上書きしない。
現段階での再構築はOCR本文から行うため、CSVに直接追記した解説等は後工程で保持方式を実装するまで再構築しない。

## 識別と原典
- `question_id`: `{year}-{REG|RET}-{BASIC|APT|APPLIED}-{number}`。基礎は群-番号、適性・専門は二桁の番号。
- `year`: `H23`〜`R07`、`exam_session`: `REG` / `RET`。`R01`と`R01_retest`は別回。
- `source_year_directory`: 保存先のディレクトリ名。再試験は`R01_retest`。
- `source_page` / `source_page_end`: PDF物理ページ（1起算）。印刷ページとは別。
- `heading_line_index`: 当該ページOCR JSON内の行番号（0起算）。`heading_bbox`は正規化座標、左下原点。
- `printed_question_number`: 公式正答表の表記。平成23・24年度専門はIV、以後はIIIであり、IDは科目の意味で統一する。
- `question_text_file`: 未校正OCRによる問題単位のローカル作業ファイル。確定問題文・配布用本文ではない。
- `sources/index02021.html`は問題リンク一覧、`sources/answers_index.html`は正答リンク一覧の保存。後者はCP932。
- 公式正答は8回分個別PDFと平成23〜30年度合冊PDFの計9件。合冊を架空の年度ファイルへ分割しない。
- 問題PDF48件は763ページ。R07基礎の末尾1ページは認識文字なしで、番号集合が一致するため空白ページとして扱った。

## 確認レベル
`answer_verified=true`は文字層のある公式表の番号・正答を抽出し、全問題との集合一致・値域・重複を検証したことを表す。解説の正しさの検証ではない。
特殊扱い6件の表と注記は画像でも確認した。その他の表の全セルの画像目視確認は未実施。

`boundary_verified=true`は目視確認して補正した2件のみ。それ以外も独立に認識された見出しと公式番号が一致するが、全見出しを目視したわけではない。

`classification_verified=false`は全行で維持する。分類根拠は語句照合と15件の内容点検による補正であり、Astraによる専門査読前。
`summary_verified=false`。現時点の`question_summary`は「テーマ＋問題形式」の索引用仮要約。条件・数値・選択肢を含む正確な要約は未作成。
`needs_manual_verification=true`は全行。OCRの数値・化学式・数式・図表・法令文は校正前。
`requires_calculation` / `requires_figure` / `requires_law`は根拠語があればtrue、判断未了はunknown。未検出をfalseとして扱わない。
難易度・優先度・解説・誤答解説・関連問題は空欄（後工程）。空欄を「不要」「易問」と読まない。

## 正答の表現
- `single`: 選択肢番号1〜5。
- `multiple_accepted`: `1|5`など。複数正答を単一番号へ潰さない。
- `all_awarded`: `ALL`。不適切出題による全員得点で、全選択肢が内容上正しいという意味ではない。
- 正答訂正: 現行公式表の訂正済み番号と注記を保存（H26基礎5-3は5）。
- `answer_source_file` / `answer_source_page`で正答原典へ戻れる。公式注記全文はanswers_official.csv・answer_exceptions.csvに残す。

## 分類体系（提案段階）
基礎大分類は公式の5問題群に従う。群内に数学・法律・倫理等が現れることがあるため、中・小分類でその内容を記録し、公式群を学問分類へ無断で置換しない。
適性は法律・倫理・安全等の学習章を大分類とする。実際の出題に合わせて「技術と社会・科学技術政策」を提案追加した（R07適性7）。
応用理学は物理及び化学／地球物理及び地球化学／地質の3大分類。物理探査は地質の主分類にまとめ、物理学的基礎との交差参照を後工程で追加する。
有機・高分子化学を`12_organic_polymer.tex`に独立させる提案を追加した。従来のotherへ多数の化学問題を収容することを避けるためである。
`middle_category`は学習章、`minor_category`・`topic`は出題概念の初期タグ、`subtopic`は認識された根拠語。小分類は専門レビューで統合・分割を要する。
規則・補正を`config/taxonomy.json`、`scripts/classify_questions.py`、`config/classification_overrides.json`に残す。
複数領域を含む問題は現状1主分類。複数タグの正規化テーブルを追加するか、査読1で決定する。

## 査読後に決める評価方法
難易度は受験者の物理・数学の既知知識を基準に、必要な専門知識、推論段数、計算量、図表依存を別軸で評価して1〜5へまとめる案。
優先度S/A/B/Cは頻度・基礎性・他テーマへの波及・得点効率・学習時間に基づく。頻度だけでは決めない。
類似問題は主題と解法を軸に候補を生成し、数値・否定表現・条件の相違を確認して人手承認する案。OCRの文字類似だけで同一問題と確定しない。
統計では16回の「試験回」頻度と15の「年度」頻度を分ける。令和元年度再試験を同年度の別回として集計する。
